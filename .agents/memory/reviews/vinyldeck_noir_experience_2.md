# vinyldeck_noir_experience_2

## Visuals (from PNG)

- A minimalist, dark cinematic aesthetic.
- The interface features a large, prominent vinyl record centered on the screen with a grayscale, abstract center label marked "A-SIDE".
- Track metadata ("Midnight Echoes", "The Synthwave Collective") is displayed directly below the platter in a clean, sans-serif font.
- The bottom navigation bar contains playback controls (PREV, PAUSE, NEXT, QUEUE, LYRICS) using outlined icons with a thin progress line running along the very top edge of the navigation bar.

## Behavior (from HTML)

- Background features a CSS noise texture overlay (`feTurbulence`) to give an analog feel.
- The vinyl record rotates continuously via a CSS `spin` animation (`4s linear infinite`).
- The record's texture is built using a complex conic-gradient to simulate lighting reflections, while the grooves are created using multiple nested absolute `div`s with faint white borders.
- An ambient radial glow sits behind the record for added depth.

## Summary

A very minimal, centralized vinyl playback view. The visual focus is almost entirely on the rotating record and its lighting effects, emphasizing the tactile feel through CSS noise and gradient-based vinyl reflections.
