# vinyldeck_quick_theme_selector_1

## Visuals (from PNG)

- A compact, centered "Aesthetics" floating popup panel using a glassmorphic design (blurred background, faint translucent border).
- Contains a "THEMES" section with circular preview buttons for "Noir" (dark), "Aurora" (purple/blue), and "Vapor" (cyan/pink).
- Includes an "EFFECTS" section with custom-styled range sliders for Bloom Intensity and Particle Density.
- Bottom section features quick toggle switches for "Pure OLED Black" and "Mini-Player Overlay".
- Set against an atmospheric dark background simulating a radial gradient.

## Behavior (from HTML)

- Uses pure CSS animations: `.vinyl-spin` makes the inner circles of the theme buttons rotate infinitely.
- Theme buttons have hover effects that trigger specific box-shadow glows (`theme-glow-noir`, `theme-glow-aurora`, `theme-glow-vapor`).
- Includes custom CSS styling for `-webkit-slider-thumb` to make the range sliders match the sleek, high-end look.
- Custom checkbox styling transforms standard inputs into smooth, animated toggle switches.

## Summary

The first iteration of the quick theme selector focuses on a robust CSS-only implementation of a glassmorphic popup, providing a visually rich but static preview of theme customization options and effects.
