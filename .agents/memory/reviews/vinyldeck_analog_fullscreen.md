# vinyldeck_analog_fullscreen

## Visuals (from PNG)

- A fullscreen playback experience with a distinct warm, vintage "analog" aesthetic.
- The color palette heavily features "warm-bronze", "warm-cream", and "vinyl-black".
- A large vinyl record dominates the center of the screen, surrounded by a soft, glowing bronze ring.
- A highly detailed, skeuomorphic tonearm (featuring pivot, arm, and headshell) is positioned over the record.
- The center label is stylized like a classic vinyl record, with typography referencing "33 ⅓ RPM" and "Stereo".
- The bottom features large, tactile playback controls, prominently featuring a large bronze Play/Pause button.

## Behavior (from HTML)

- Uses custom CSS shapes, box-shadows, and gradients (`bronze-metal`) to construct the skeuomorphic tonearm.
- The vinyl record rotates continuously via a `spin-slow` animation.
- A static SVG `<filter>` is applied as a noise overlay (`bg-noise`) to simulate analog texture across the entire screen.
- Features a subtle glowing ring behind the vinyl (`glow-ring`) that enhances the depth.

## Summary

A beautiful fullscreen player mode that leans heavily into a vintage, warm analog identity. It uses complex CSS gradients and shadows to render a highly detailed, skeuomorphic tonearm and utilizes a warm bronze color palette to create an inviting, classic Hi-Fi listening experience.
