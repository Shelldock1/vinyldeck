# vinyldeck_noir_theme_1

## Visuals (from PNG)

This design represents a foundational, static state of the main "Noir" app theme. It features a dark background with very subtle, desaturated ambient orbs (`bg-surface-variant` and `bg-on-secondary`). The layout consists of a large central vinyl record with a skeuomorphic tonearm on the right. Below the record is a wide, pill-shaped glassmorphic panel containing the track info ("After Hours"), playback controls, and a volume slider. A top navigation bar and a hidden mobile bottom-nav are also present. The album art is a moody red and black abstract macro shot.

## Behavior (from HTML)

This file is a purely static visual mockup. There is absolutely no JavaScript included in the file.

- **Animations**: It relies entirely on basic CSS animations. The vinyl has an `8s linear infinite` spin applied via the `.animate-spin-slow` class.
- **Interactions**: There are basic CSS hover states (opacity changes, color shifts) on the buttons, but no functional playback toggling, tonearm movement, or parallax effects.

## Summary

"Noir Theme 1" serves as a baseline structural and visual mockup for the app-style Noir layout. It establishes the dark aesthetic, the central vinyl placement, and the glassmorphic control pill, but completely lacks the interactive behaviors, JavaScript logic, and physical lighting simulations found in the "high fidelity" variants of this same layout.
